Light novels are read in the app's own reader, through **LNReader plugins** added as a reading source.

- The **EPUB** export is what turns a downloaded novel into a file you can read elsewhere.
- The exact formats a source offers depend on the source: some serve chapters as text, some as files.
- Downloads depend on the source supporting them, and land in the same Downloads area as video downloads.

Because formats vary by source, the export options available for a given novel vary with the source it came from. If a particular novel will not export, try another source for it.
