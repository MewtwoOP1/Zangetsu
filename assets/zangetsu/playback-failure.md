1. **Try another server** in the sources sheet. Links expire, and a fresh server usually has a fresh link.
2. **Try another source** for the same title. This is the step that decides whose problem it is — see the entry on app versus source.
3. **Update the source.** A changed player page is the usual cause of a link that no longer resolves.
4. **Complete any browser check** that opens while resolving — a Cloudflare challenge remembered once fixes the link it was blocking.
5. **Try an external player** from the player menu. If it plays there, the stream is fine.

If it fails on every server of every source, it is worth a bug report — include the exact error text and one episode it happens on.
