Open **Settings → Sources → Source health**.

This tests your installed sources and marks the dead ones. Search puts healthy sources first and skips ones that just failed, so clearing out dead sources genuinely speeds things up.

Work through it in this order:

1. Try the same title from another source. If a second one plays, the first is broken and there is nothing to fix on your end.
2. Run Source health and remove what it marks dead.
3. Update your sources. When a site changes, its source usually gets fixed within days, and the sources screen shows a badge when updates are available.
