1. Open **Settings → Sources**.
2. Pick the ecosystem the repository belongs to.
3. Choose **Add repository**.
4. Paste the repository URL and let it load.
5. Install the sources you want. They show up in the source switcher at the top of the home screen.

Installed sources can be updated from the same screen when their author publishes a new version, and the screen shows a **badge when updates are available**.

On older builds the same screen is reached through **Settings → Sources → Add repo** or **Settings → Sources**.

If a repository will not load at all, see the troubleshooting entry for repositories that fail to load.
