Zangetsu understands several plugin formats, so extensions written for other apps work here too.

- **Zangetsu** — the app's own lightweight JavaScript sources. These are the only ones that work on iOS.
- **CloudStream** — `.cs3` extensions.
- **Aniyomi / Mihon** — installed as Android extension packages. Aniyomi covers anime, Mihon covers manga.
- **LNReader** — plugins for light novels.

Add each one through **Settings → Sources → pick that ecosystem → Add repository**. The switcher only shows sources that fit the mode you are in, so a reading mode with no sources means you have not added a reading ecosystem yet.
