The release notes for every build are on the upstream repository's releases page:
https://github.com/Spyou/Zangetsu/releases

Each release lists what changed, and fixes are named in the notes. To check a specific problem:

1. Open the releases page and read the notes of the newest builds, newest first.
2. Look for your symptom in the **fix** lines — "fixed", "buffering", "subtitles", "Android TV", "sources".
3. If a fix is listed for a version newer than the one you are on, update and try again.

The app also checks GitHub Releases and offers the update in-app, so the newest build is usually one tap away.

If the notes do not mention your problem in any release, it is probably not fixed yet, and the honest answer is that it is not confirmed fixed.
