A source is a small plugin that knows how to search one website and find video for a title.

Sources come from **repositories** — a URL that lists plugins the app can install. Add a repository, install sources from it, and the app can then search them.

Installed sources appear in the source switcher at the top of the home screen. The switcher only offers sources that fit what you are doing: watching and reading are separate modes, so a mode that looks empty means you have not added a source for that mode yet.
