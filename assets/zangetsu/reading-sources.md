Manga and novels work the same way as watching: **nothing is bundled, you add what you want**.

1. Open **Settings → Sources**.
2. Pick the reading ecosystem: **Mihon** for manga, **LNReader** for light novels.
3. **Add repository**, paste the URL, and install the sources you want.

The app has separate modes for watching and reading, and the **source switcher only offers sources that fit what you are doing**. If the reading mode looks empty, you have not added a source for that mode yet — the home screen says so and points you at the right screen.

Mihon extensions are Android packages, so they do not load on iOS. Zangetsu's own JavaScript sources do.
