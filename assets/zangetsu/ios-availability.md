Yes — there is an iOS build on **TestFlight**, and it is a beta.

One limitation is worth knowing before you install it: **CloudStream and Aniyomi / Mihon extensions are Android-only.** They rely on Android's plugin loading, which iOS does not allow. On iOS you get Zangetsu's own JavaScript sources and the built-in player, not the full source ecosystem.

Everything else — the player, downloads, trackers and your list — works the same.

If a guide mentions a CloudStream or Aniyomi repository, that part is for Android.
