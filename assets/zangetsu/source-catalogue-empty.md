A source that installs but returns nothing is usually talking to a site that has changed, moved or started blocking it.

1. Run **Settings → Sources → Source health** for that source.
2. **Update the source.** A source usually gets fixed within days of the site it reads changing, and the sources screen shows a badge when an update is available.
3. Try fewer words in the search, and try the title in its original language or as it is listed on the site.
4. Check the source's own repository or page — a source that has been withdrawn usually says so.

If another source finds the same title, the title exists and this source is the problem. If no source finds it, the title may simply not be in that ecosystem's catalogue.

Sources are community-maintained and can go down without the app knowing, so this is a source problem far more often than an app bug.
