1. Open **Settings → Sources**. The same screen you added the repository from.
2. Look for the **badge** — the screen shows one when an update is available.
3. Update the source or the repository. Installed sources can be updated from the same screen when their author publishes a new version.
4. If a source will not update, **remove it and install it again** from its repository, which also picks up a newer version.

A source usually gets fixed **within days** of the site it reads changing, so updating is the first thing to try when a source that used to work stops.

Note that this updates the **extension**, not the app. Updating the app itself is a separate step — see the update entry.
