Sources work exactly as they do on a phone, and the screens are the same ones adapted for a remote.

Adding a repository means **typing a URL**, which is the one genuinely awkward moment. The guide's advice: if you use the app on a phone as well, it is **easier to get set up there first** — add the repository and install the sources on the phone, and they will be there on the TV as well once the app is on the same account and the list is synced.
