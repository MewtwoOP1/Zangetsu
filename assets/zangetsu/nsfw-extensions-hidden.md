An extension that is flagged NSFW is **hidden until NSFW content is switched on**.

1. Open the app's privacy or advanced settings and **turn NSFW on**.
2. Go back to **Settings → Sources** — the extension is there.

This is the answer the maintainer gives on the app's own issue tracker for extensions that install but never appear, including Mihon and Keiyoushi manga extensions.

Related: a repository that lists its extensions but installs none is usually a repository problem rather than this setting — check the repository URL and the ecosystem you added it under.
