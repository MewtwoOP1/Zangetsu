The app supports **profiles** and a **profile PIN**, so a shared device can keep separate lists apart and stop someone opening yours.

1. Create or switch profiles from the profile area in the app.
2. Set a **PIN** on the profile that holds your own list.
3. **Offline access** is what the app grants before a PIN is entered, so a downloaded profile can be used without unlocking the account each time.

An optional Zangetsu account exists only to sync your list across devices. If you never signed in, the app still works — it just keeps everything on the device.

If the profile or PIN options are missing for you, tell the app version and platform, because that screen has changed between releases.
