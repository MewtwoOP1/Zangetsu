A title page carries a **"Wrong title?"** option, and it is the route the maintainer points people at when a source maps an episode to the wrong title.

1. Open the title and use **Wrong title?**.
2. Pick the title it should be, or report the mapping.
3. The source's author is told, which is what actually fixes it.

This is for a **mapping** problem — the right title, the wrong episode attached. It is not a fix for a broken stream: for that, pick another server or another source.

Several issues on the app's tracker were closed as "Source issue" for exactly this reason.
