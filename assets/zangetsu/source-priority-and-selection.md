- **Search** groups results by source, so you can see at a glance who has the title.
- The **chip at the top of the home screen** switches which source you are browsing.
- In the player, the **sources sheet** lets you pick another server, and **your choice is remembered for that title**.
- **Auto Resolve** picks the first server that responds. If that one is poor, open the sources sheet and pick another.
- Search puts **healthy sources first** and skips ones that just failed, so clearing out dead sources genuinely speeds things up.

A source that offers only one file per quality shows those as **separate servers** in the sources sheet instead of as quality choices.
