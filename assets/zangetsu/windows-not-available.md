Not yet. The app's own roadmap lists **Windows as "in progress"**, and there is no Linux or macOS build either.

What exists today:

| Platform | Status |
|:--|:--:|
| Android | Available |
| Android TV | Available |
| iOS | Beta (TestFlight) |
| Windows | In progress |

On a computer, the practical option today is an **Android emulator** or an Android TV box, or the iOS build on Apple hardware. The app ships ARM-only libraries, so an x86 Android TV emulator will not run it.
