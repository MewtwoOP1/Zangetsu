A repository is **a URL that lists plugins the app can install**. Paste it into Add repository and the app reads the list.

The important part: repositories are **community-run**. The Zangetsu project does not run, host, endorse or control them, and any of them can change or disappear without notice. When a repository stops loading, that is the repository, not the app.

Only one of the repositories the official guide points at is the app project's own. The rest are run by other people, and what they contain is not something the app project chooses.
