Metadata comes from the **source**, not from the app, so the wrong poster or the wrong description is usually the source's data.

1. Open the same title from **another source** and compare.
2. If the metadata differs between sources, each is reading its own site, and the one that looks wrong is that site's fault.
3. **Auto Resolve** is what matches a catalogue entry to the right stream, so check it before assuming the entry itself is wrong.
4. Some titles genuinely have several names — an original title, a romanised title and a fan translation — and different sites pick different ones. That is not a bug.

If **every** source shows the same wrong metadata for a title, it is worth reporting with the title name and what the correct details are.
