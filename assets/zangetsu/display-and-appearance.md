The app's Settings area holds the display and appearance options, the subtitle styling used by the player, and the interface language. On Android TV the interface is chosen by the app itself when it detects a TV, so there is no separate TV theme to pick.

Subtitle **styling** — size, background and outline — is set in the player and applies to the subtitle tracks the stream actually carries.

If an option you expect is not there, check the app version: the settings screens have changed between releases, and the release notes list what moved.
